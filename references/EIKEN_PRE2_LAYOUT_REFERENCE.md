# 準2級 Reading 紙面の観測

出典と確認日は [OFFICIAL_SOURCES](OFFICIAL_SOURCES.md)。3回ともPDF3〜9ページを個別画像で比較した。これは紙面の観測であって、将来も不変な公式仕様という意味ではない。

| 教材モデル | 公式PDFページ（1始まり） | 観測内容 |
|---|---:|---|
| R1 | 3 | 大問1：問1〜10。短い4肢の横配置等 |
| R2 | 4 | 大問1：問11〜15。熟語等の横・2列配置 |
| R3 | 5 | 大問2：4会話。空所は1・1・1・2、計5問 |

| R6 | 8 | 大問4B：題名＋4段落の本文 |
| R7 | 9 | 大問4B：問26〜29の4問 |

英文本文・設問はセリフ系、メール本文はサンセリフ系。大問3のタイトルと4Bのタイトルでは書体の役割が異なる。問題番号帯、会話のラベル、メール枠を見て配置を設計する。公式の正確な書体名やpt値、物理的な用紙寸法を実測したとは扱わない。

A4・余白・12〜13pt等は [LAYOUT](../LAYOUT_MASTER_PROMPT.md) の再現用設定。ここでの7ページはReading問題部分だけであり、公式冊子全体でも完成教材全体でもない。

## 固定で点検する不良

2級の31問やP4Bの5問混入、会話を5本に分割、長文空所の3段落・3空所化、メール枠の欠落、最後の1問だけの別ページ化、本文の過度な縮小、人名始まり段落の見出し化、日本語の欠字、旧版PDFの誤確認を点検する。

実際の教材をこの仕様で生成・変換して全ページ確認するまで、「このテーマの紙面を検証済み」とは言わない。
