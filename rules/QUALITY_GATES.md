# 品質ゲート

各条件に、適用判断、検証した版、証拠、状態を記録する。内部資料であり、生徒用教材へ転載しない。機械合格と編集上の合格を分離する。

| ID | 条件 | 検証 |
|---|---|---|
| G01 | 級・技能・現行形式・参照回の区別 | JSON構造＋公式を実際に確認 |
| G02 | 29問、パート配分、会話4本の空所配分 | CLI |
| G03 | 全4肢・ID・空所・正答キーの一致 | CLI＋最終紙面 |
| G04 | 出典・訳・解説・肢別理由の記録が存在 | CLI（中身の正しさは保証しない） |
| G05 | 正答の全要素が支持され誤答を排除できる | 全候補を代入・本文照合・キーを隠した再解答 |
| G06 | 英文自然さと準2級の処理負荷 | 公式実例との編集比較。語数はCLI警告 |
| G07 | 作品固有の題材、事実と架空枠の区別 | 出典の該当箇所を確認 |
| G08 | 紹介・語彙・画像・別問の答え漏れがない | 横断した編集確認 |
| G09 | 訳の意味保持と自然な日本語 | 日本語単独＋英文対照 |
| G10 | 内容正本とDOCX・PDF・解答解説が一致 | 最終版の文字列・ID照合 |
| G11 | 用紙・役割別書体・枠・分断・欠字に不良なし | 出力実測＋全ページ個別画像確認 |
| G12 | 指定の出力順、全訳が最後、内部メモなし | 最終ファイル確認 |

G01〜G12は教材制作のゲート。G05〜G12等の意味・事実・紙面は現在のCIでは自動判定しない。必要なゲートを未実施のまま「完成」「本番と同じ難易度」としない。

語数目安外・長い文・正答位置の偏りは再検討を促す警告。数値だけで自動不合格や自動合格にはしない。問題数・4択・キー不整合・訳の欠落などの構造エラーは修正が必要。

文書更新のみの場合は、関連文書と参照数値の整合、相対リンク、コードのテスト、GitHub保存結果を確認する。教材生成・PDF検査・学習者試行は対象外であり、実施済みとは報告しない。
