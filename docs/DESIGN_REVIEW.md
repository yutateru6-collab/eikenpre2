# 先の計画を見直した点

この文書は設計上の判断と検証可能な変更をまとめたもの。教材の品質合格記録ではない。

| 先の計画の弱点 | 今回の修正 |
|---|---|
| ファイルをコピーして級名・語彙を変えるだけになり得る | 会話・空所・メール・説明文を準2級の構成に再設計 |
| 5問の会話を5本と誤解する余地 | 4会話、空所1・1・1・2をJSONとテストへ固定 |
| 2級の数字とファイル参照が複製後に残る | 準2級専用JSONを数値の正本にして内部整合を検査 |
| 「2級専用」と説明したが元MASTERには準1級節もある | 上位級への切替節を引き継がない |
| 語数・レイアウト目安を公式基準と混同し得る | 公式記載、3回の観測、編集用目安を明確に区別 |
| 有名場面だけで全パートを作ると架空メールが原作に混ざる | source_based / fiction / mixedを分ける |
| 「ファンでも本文なしには絶対解けない」は保証不能 | 外部知識を不要にし、クイズ化・答え漏れ・候補だけの手掛かりを点検 |
| 誤答を難しくし過ぎると準2級でなくなる | 会話の応答、局所的な理由・照応・自然な言い換えを中心にする |
| 文書に「検査」と書くだけでは実際に検出できない | 構造CLIと壊したデータを使う回帰テストを実装 |
| 検査欄が埋まれば内容も正しいと誤解される | 構造検査・意味確認・紙面確認・学習者試行を分離 |
| 複製先と元の改良が将来ずれる | 参照元の版を記録。共通方針の変更時は両者を比較し、無条件の自動同期はしない |

## 採用したトレードオフ

別リポジトリは級の混入を減らす一方、共通ルールの保守が二重になる。今回は既存教材を壊さないことを優先した。将来多くの級を扱うなら、共通ルールと級別プロファイルの分離を検討できるが、今回は元リポジトリを組み替えない。

本文の題材性と語彙・会話の自然さは別に評価する。長文は確認済みの固有情報を中核にし、短文は無理なエピソード説明を避ける。標準7ページを目標とするが、大文字版等のユーザー指定は別版として扱う。

## 残る限界

参照は3回の小標本。集計は表示確認した転記に基づき、全出題の固定範囲ではない。構造CLIは英文の意味・史実・翻訳の正しさを理解するエンジンではない。AI生成、DOCX/PDF描画、全ページの自動意味検査は未実装。実際の教材作成時に編集・変換・目視が必要。

受験者による試行は未実施。本番と同じ正答率、識別力、合格可能性を保証しない。生成したサンプル教材の印刷検証もこの初期登録では実施していない。テスト用データは構造を試すための合成データであり、教材として使わない。
