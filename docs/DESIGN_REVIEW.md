# 初期計画の評価と改訂理由

2026-09-11 / v1.0。対象は新設 `eikenpre2`。元の `eikenreading` の参照コミットは `b2e5e107157f27f97808866b53e106fe8801107a`。元のリポジトリへの書き込みは行わない。

## 結論

別リポジトリで分離する方針は、既存教材の規則を壊さず始めるには妥当。ただし「コピーして級名と語数を置換」では足りない。元のMASTERには2級だけでなく準1級の節もあり、「2級のみ」とする以前の説明は厳密ではなかった。準2級と無関係な級別指示を削り、共通思想だけを引き継ぐ。

| 初期計画の弱点 | 今回の対応 | 確認方法・残る限界 |
|---|---|---|
| 会話5問という合計だけでは単位を誤る | 4会話、空所数1/1/1/2、問16〜20を仕様化 | 構造検査で5会話・空所不足を検出 |
| 2級の長文・ページ型が残る危険 | 2空所、メール3問、説明文4問、Reading7ページを独立定義 | 公式3回の画像を確認。実教材のレンダリングは別途 |
| 「高校中級」「語彙を易しく」だけでは負荷が曖昧 | 各パートの照合範囲・発話・完成文語数を区別 | 3回分の標本であり難易度を統計推定したものではない |
| 実測値を公式規格と取り違える | 公表構成・標本観察・制作設定を別管理 | 公式更新時はプロファイルとテストも更新 |
| 長いテーマ紹介や画像の必須化 | 短い紹介を既定とし、試験用では省略 | 前付からの答え漏れは内容レビューが必要 |
| 実話優先を全ての会話へ硬直的に適用 | 本編の事実と架空の教材場面を区別 | 創作表示だけでは作品内の事実の正確さは保証されない |
| プロンプトを増やすだけで遵守を期待 | 実行可能な構造検査と回帰テストを追加 | 意味・自然な訳・最終紙面は自動判定しない |
| 正解番号を別管理して食い違う | 安定IDから表示番号を導出 | 別途手入力した配布物は最終照合が必要 |
| 受験者未試行なのに本番難度を保証する | 出典に基づく編集上の校正と、実測難度を区別 | 受験者試行・識別力・誤答率は未実施 |

## 継承した点と変えた点

実際の代表的エピソード、根拠に基づく全4肢の検査、自然な日本語、全文和訳を最後に置くこと、内部検査表を生徒用に載せないこと、最終WordからPDFへ変換して全ページ画像を見ることは継承する。

均等配分・3連続禁止を公式条件にしない方針は元のリポジトリですでに修正されていた。今回新しく発見して初めて直した、と説明しない。準2級でも公式正答分布を確認し同じ扱いにした。

本文の書体・行間と公式と同じページ数が両立しない場合、文字縮小で隠さず、内容量の差し戻しか広い別版を明示する。読みやすさと本番の配置の両方を、実際の出力で検査する。

## 運用上のトレードオフ

独立リポジトリは将来、共通ルールが二重管理になる。元の更新を無検証で自動取り込みせず、変更点を比較して準2級に適用できるものだけ反映する。数値の正本は仕様JSONに集約し、READMEや説明文との食い違いも修正する。

構造検査は最低限のデータ欠陥を除くもので、正しい出典URLを書くことや根拠欄を埋めることの真偽を保証しない。テスト用の合成データは、構造検査の試験に使うだけで生徒用問題の見本にはしない。

## 今回の完了範囲

準2級専用の指示・参照・データ契約・Python構造検査・テスト・CI定義を保存し、その実装を検査する。実際の生徒用29問の生成、Word/PDFレンダラー、最終紙面の検査、受験者への試行はこの変更に含めない。将来のAI実行が規則を必ず守るという保証もしない。
